# Câu điều kiện hỗn hợp và đảo ngữ điều kiện

## Công thức

| Kiểu | Mệnh đề điều kiện | Mệnh đề chính | Ý nghĩa |
|---|---|---|---|
| Hỗn hợp 3 → 2 | If + had + V3 | would / could / might + V (now) | Quá khứ khác đi thì **hiện tại** đã khác |
| Hỗn hợp 2 → 3 | If + V2 (be → were) | would / could / might + have + V3 | Đặc điểm **hiện tại / lâu dài** khác đi thì **quá khứ** đã khác |
| Đảo ngữ loại 1 | Should + S + V nguyên mẫu | will / can / please + V | = If + S + V (trang trọng, hay dùng trong email, thông báo) |
| Đảo ngữ loại 2 | Were + S + adj / N / to V | would / could + V | = If + S + were / V2 |
| Đảo ngữ loại 3 | Had + S + (not) + V3 | would / could + have + V3 | = If + S + had (not) + V3 |
| But for / Without | But for / Without + N | would (have) + V / V3 | = If it were not for / If it had not been for + N |

- Khẳng định: *If we **had hired** more staff last year, we **would be** less busy now.*
- Phủ định: ***Had** the supplier **not** delayed the shipment, we **would have met** the deadline.*
- Nghi vấn: *If you **had taken** that job, **would** you **be living** in Singapore now?*

## Cách dùng

1. **Hỗn hợp 3 → 2**: điều kiện trái thực tế trong quá khứ, kết quả trái thực tế ở hiện tại (thường có *now, today, still*).
   *If I **had accepted** the offer, I **would be working** in Da Nang now.*
2. **Hỗn hợp 2 → 3**: điều kiện là đặc điểm / tình trạng **lâu dài ở hiện tại**, kết quả là việc đã (không) xảy ra trong quá khứ.
   *If Minh **were** more careful, he **wouldn't have made** that mistake yesterday.* (Minh vốn không cẩn thận)
3. **Should + S + V**: điều kiện có thể xảy ra nhưng không chắc, rất hay gặp trong thư từ TOEIC.
   ***Should** you **have** any questions, please contact us.*
4. **Were + S + to V / adj**: giả định trang trọng. *Were the price **to rise** again, we would change suppliers.*
5. **Had + S + V3**: giả định quá khứ. ***Had** I **known** about the strike, I would have rebooked.*
6. **But for / Without + danh từ**: "nếu không có…". *But for your support, the project would have failed.*
   Dạng đảo ngữ tương ứng: *Were it not for…* (hiện tại), *Had it not been for…* (quá khứ).

## Dấu hiệu nhận biết

- Mệnh đề If ở quá khứ (*last year, in 2020*) nhưng mệnh đề chính có *now, today, still* → hỗn hợp 3 → 2.
- Mệnh đề If nói về tính cách / tình trạng lâu dài, mệnh đề chính có *yesterday, last week* → hỗn hợp 2 → 3.
- Câu bắt đầu bằng **Should / Were / Had** + chủ ngữ, không có *if*, có dấu phẩy ngăn hai vế → đảo ngữ điều kiện.
- *But for / Without* + cụm danh từ, mệnh đề chính có *would* → điều kiện ẩn.

## Lỗi thường gặp

- ~~If I had taken the job, I would have lived in Hanoi now.~~ → … I **would be living** in Hanoi now.
- ~~If had I known~~ → **Had I known** (đảo ngữ thì bỏ *if*).
- ~~Hadn't I known~~ → **Had I not known** (không rút gọn *not* trong đảo ngữ điều kiện).
- ~~Should you will need help~~ / ~~Should you needed help~~ → **Should you need** help.
- ~~Were the price rises~~ → **Were the price to rise**.
- ~~But for you helped me~~ → **But for your help** (sau *but for* là danh từ, không phải mệnh đề).

## Phân biệt với các chủ đề dễ nhầm

- **Loại 3 vs hỗn hợp 3 → 2**: cùng *If + had V3*, nhưng loại 3 có kết quả *would have V3* (quá khứ), hỗn hợp có *would + V* (hiện tại).
- **Đảo ngữ điều kiện vs đảo ngữ phủ định** (*Never have I…, Not until… did…*): đảo ngữ điều kiện thay cho *if*, chỉ dùng *should / were / had*.
- **Should (đảo ngữ) vs should (nên)**: *Should you need help* = *If you need help*, không có nghĩa "nên".
- **But for (nếu không có) vs but (nhưng) / except for (ngoại trừ)**.
