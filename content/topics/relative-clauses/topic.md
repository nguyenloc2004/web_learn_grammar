# Mệnh đề quan hệ (Relative Clauses)

## Công thức

| Đại từ / trạng từ quan hệ | Thay cho | Chức năng | Ví dụ |
|---|---|---|---|
| **who** | người | chủ ngữ (hoặc tân ngữ, thân mật) | *the man **who** called* |
| **whom** | người | tân ngữ, sau giới từ | *the candidate **whom** we hired*, *with **whom*** |
| **which** | vật | chủ ngữ / tân ngữ, sau giới từ | *the report **which** you sent* |
| **that** | người / vật | chủ ngữ / tân ngữ (chỉ mệnh đề xác định) | *the software **that** we use* |
| **whose** + N | người / vật | sở hữu | *the client **whose** order was late* |
| **where** | nơi chốn | = in / at which (mệnh đề đủ thành phần) | *the hotel **where** we stayed* |
| **when** | thời gian | = on / in which | *the day **when** we met* |

- Khẳng định: *The employee **who** won the award is from Hue.*
- Phủ định: *The supplier **that** didn't deliver on time has been replaced.*
- Nghi vấn: *Is this the file **which** you need?*

## Cách dùng

1. **Mệnh đề xác định** (không có dấu phẩy): cần thiết để xác định danh từ. Dùng được *that*; có thể lược đại từ làm tân ngữ.
   *The laptop (that) I bought is fast.*
2. **Mệnh đề không xác định** (có dấu phẩy): chỉ bổ sung thông tin. **Không** dùng *that*, **không** lược bỏ đại từ.
   *Ms. Lien, **who** leads the team, will join us.*
3. **Giới từ + whom / which**: *the colleague **to whom** I spoke*, *the project **on which** we worked*.

## Dấu hiệu nhận biết

- Danh từ phía trước là **người** hay **vật**?
- Sau chỗ trống là **động từ** (→ chủ ngữ: who / which / that), **S + V** thiếu tân ngữ (→ whom / which / that), **danh từ** (→ whose), **S + V đầy đủ** (→ where / when).
- Có **dấu phẩy** trước chỗ trống → không dùng that.
- Có **giới từ** ngay trước chỗ trống → whom / which.

## Lỗi thường gặp

- Lặp đại từ trong mệnh đề: ~~The report which you asked for it~~ → The report which you asked for.
- Dùng *which* cho người, *who* cho vật.
- ~~who their orders~~ → **whose** orders.
- Dùng *that* sau dấu phẩy hoặc sau giới từ: ~~, that has worked~~, ~~with that~~.
- Dùng *which* khi mệnh đề đã đủ thành phần: ~~the hotel which the conference will be held~~ → **where** / **in which**.

## Phân biệt với các chủ đề dễ nhầm

- **where vs which** cho nơi chốn: *the city **where** I live* vs *the city **which** I visited* (which là tân ngữ của visited).
- **what vs which / that**: *what* = the thing that, không đứng sau danh từ. *This is **what** I need.* vs *This is the file **that** I need.*
- **Mệnh đề quan hệ vs rút gọn mệnh đề quan hệ**: *the man **who is sitting** there* → *the man **sitting** there*.
