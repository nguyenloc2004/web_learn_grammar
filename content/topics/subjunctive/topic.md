# Thức giả định; It's time, would rather, had better

## Công thức

| Cấu trúc | Theo sau | Ví dụ |
|---|---|---|
| suggest / recommend / request / demand / insist / require / ask / propose + **that** | S + **V nguyên mẫu** (mọi ngôi) | *The manager **suggested that** he **attend** the course.* |
| It is essential / important / vital / necessary / imperative + **that** | S + **V nguyên mẫu** | *It is **essential that** every guest **register** online.* |
| Danh từ: suggestion / request / recommendation / requirement + **that** | S + **V nguyên mẫu** | *Her **request that** the fee **be** waived was accepted.* |
| It's (high / about) time | S + **V2** (quá khứ đơn) | *It's **high time** we **updated** the website.* |
| It's time | **to V** | *It's **time to update** the website.* |
| S + would rather | **V nguyên mẫu** (cùng chủ ngữ) | *I'd **rather work** from home today.* |
| S1 + would rather + S2 | **V2** (hiện tại / tương lai) | *I'd **rather you sent** it tomorrow.* |
| had better | **V nguyên mẫu** / **not V** | *You **had better** check the figures again.* |

- Khẳng định: *They **insisted that** the contract **be** reviewed by a lawyer.*
- Phủ định: *We **recommend that** customers **not open** the package before delivery.* / *You **had better not** be late.*
- Nghi vấn: ***Would** you **rather** I **called** the client myself?* / ***Is** it **essential that** everyone **attend**?*

## Cách dùng

1. **Giả định sau động từ đề nghị, yêu cầu**: động từ trong mệnh đề *that* giữ **nguyên mẫu**, không thêm -s, không chia thì,
   dù động từ chính ở quá khứ. Phủ định: **not + V**; bị động: **be + V3**.
   *The client **demanded that** the order **be shipped** immediately.*
2. **Giả định sau tính từ chỉ sự cần thiết**: *essential, important, vital, necessary, crucial, imperative*.
   *It is **important that** she **not miss** the deadline.*
3. **It's (high) time + S + V2**: đã đến lúc (đáng lẽ phải làm rồi). Dù dùng V2 nhưng nói về hiện tại.
4. **Would rather**: thích hơn / muốn hơn. Cùng chủ ngữ + V nguyên mẫu; khác chủ ngữ + V2 (mong ai đó làm gì).
   *I'd rather **not discuss** it now.* / *I'd rather **you didn't discuss** it now.*
5. **Had better + V**: lời khuyên mạnh, ngụ ý có hậu quả nếu không làm. Phủ định **had better not + V**.

## Dấu hiệu nhận biết

- Trước chỗ trống có *suggest, recommend, request, demand, insist, require, propose, ask* + **that** + chủ ngữ → V nguyên mẫu.
- *It is essential / vital / necessary / important that* + chủ ngữ → V nguyên mẫu.
- *It's time / It's high time / It's about time* + chủ ngữ → V2.
- *would rather* + chủ ngữ khác → V2; *had better* → V nguyên mẫu (không *to*).

## Lỗi thường gặp

- ~~The manager suggested that he attends~~ → … that he **attend**.
- ~~recommended that we don't sign~~ → … that we **not sign**.
- ~~insisted that the goods are delivered~~ → … that the goods **be delivered**.
- ~~It's time we update~~ → It's time we **updated**.
- ~~I'd rather you don't call~~ → I'd rather you **didn't call**.
- ~~You had better to leave~~ / ~~You had better not to leave~~ → You had better **leave** / **not leave**.
- ~~You would better~~ → You **had** better ('d better).

## Phân biệt với các chủ đề dễ nhầm

- **Suggest + that + S + V vs suggest + V-ing**: *He suggested **that we meet** early.* / *He suggested **meeting** early.* (không dùng ~~suggest someone to do~~).
- **Thức giả định vs câu tường thuật**: sau *say / tell / report that* động từ vẫn lùi thì bình thường; chỉ các động từ đề nghị, yêu cầu mới dùng V nguyên mẫu.
- **Would rather + S + V2 vs wish + S + V2**: cùng lùi thì; *would rather* thể hiện sự ưa thích, *wish* thể hiện mong ước trái thực tế.
- **Had better vs should**: *had better* mạnh hơn, dùng cho tình huống cụ thể, có hàm ý cảnh báo.
