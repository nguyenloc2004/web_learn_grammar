# Từ chỉ lượng (some, any, much, many, a few, a little…)

## Công thức

| Từ chỉ lượng | Đi với | Ví dụ |
|---|---|---|
| many / (a) few / several / a number of | N đếm được số nhiều | **a few** complaints |
| much / (a) little / a great deal of | N không đếm được | **little** time |
| some / any / a lot of / lots of / plenty of | cả hai loại | **some** advice, **some** files |
| each / every | N đếm được **số ít** + V số ít | **every** employee **is** |
| all / most / some / none / each / many **of** | **the / these / tính từ sở hữu / đại từ** + N | **most of our** clients |
| another | N đếm được số ít | **another** option |
| other | N số nhiều / không đếm được | **other** suppliers |
| the other / the others | cái còn lại (số ít) / những cái còn lại | one … **the other** |

- Khẳng định: *We have received **a few** applications and **some** feedback.*
- Phủ định: *There is**n't much** time left.*
- Nghi vấn: *Are there **any** seats available?*

## Cách dùng

1. **few / little** (rất ít, gần như không, nghĩa tiêu cực) vs **a few / a little** (một vài, một chút, nghĩa tích cực):
   *There is **little** hope.* vs *There is **a little** time, so let's start.*
2. **some** dùng trong câu khẳng định và lời mời / đề nghị; **any** dùng trong câu phủ định, câu hỏi và sau *if*.
3. **each / every + danh từ số ít + động từ số ít**: ***Each** participant **receives** a badge.* Có **each of + the + N số nhiều**, nhưng không có ~~every of~~.
4. **most / all / none / some + of** bắt buộc có **the / these / my / our…** phía sau:
   *most **of the** staff*, *all **of our** suppliers*. Nói chung chung thì bỏ *of*: ***Most** customers prefer…*
5. **almost** là trạng từ, không đi trực tiếp với danh từ: ~~almost of the staff~~ → **almost all of** the staff / **most of** the staff.
6. **another / other / the other(s)**:
   - **another** + N số ít (thêm một cái khác): *another meeting*
   - **other** + N số nhiều: *other options*; **others** = những cái khác (đứng một mình)
   - **the other** (cái còn lại trong hai), **the others** (những cái còn lại)

## Dấu hiệu nhận biết

- Xem danh từ phía sau: đếm được số nhiều, số ít hay không đếm được.
- Có **of the / of our…** phía sau chỗ trống → most / all / none / each / some (không phải *every*, *almost*, *no*).
- Nghĩa câu tiêu cực ("only", "unfortunately", "so we cannot…") → **few / little**; tích cực → **a few / a little**.
- "Một trong hai… cái còn lại" → **the other**.

## Lỗi thường gặp

- ~~much complaints~~ → **many** complaints; ~~many information~~ → **much** information.
- ~~every employees~~ → every **employee**; ~~every of~~ → **each of**.
- ~~most of staff~~, ~~almost of the staff~~ → **most of the** staff / **most** staff.
- ~~another suppliers~~ → **other** suppliers; ~~the another~~ → **the other**.
- Nhầm few / a few vì tiếng Việt đều dịch là "ít".

## Phân biệt với các chủ đề dễ nhầm

- **Danh từ đếm được / không đếm được**: quyết định chọn many hay much, few hay little.
- **Mạo từ**: từ chỉ lượng đứng ở vị trí của mạo từ (~~the some~~, ~~a few the~~).
- **Hòa hợp chủ ngữ - động từ**: *each of / every / none of* thường đi với động từ số ít.
- **most (nhất) vs most (phần lớn)**: *the most important* (so sánh nhất) vs *most clients* (phần lớn khách hàng).
