# Đảo ngữ (Inversion)

## Công thức

| Trạng từ / cụm phủ định đứng đầu | Cấu trúc | Ví dụ |
|---|---|---|
| Never / Rarely / Seldom / Little | + trợ động từ + S + V | ***Rarely do** we **receive** complaints.* |
| Hardly / Scarcely … when | Hardly + had + S + V3 + when + S + V2 | ***Hardly had** she **arrived** when the meeting began.* |
| No sooner … than | No sooner + had + S + V3 + than + S + V2 | ***No sooner had** we **launched** the app than orders poured in.* |
| Not only … but (also) | Not only + trợ động từ + S + V, but S also V | ***Not only does** it **save** time, but it also cuts costs.* |
| Only after / Only when / Only if / Not until + mệnh đề / cụm từ | + trợ động từ + S + V (đảo ở **mệnh đề chính**) | ***Only when** the audit ended **did** we **relax**.* |
| Under no circumstances / On no account / In no way | + trợ động từ + S + V | ***Under no circumstances should** you **share** this code.* |
| So + adj / adv … that | So + adj + be + S + that … | ***So successful was** the campaign that sales doubled.* |
| Such … that | Such + be + N + that … | ***Such was** the demand that we ran out of stock.* |

- Khẳng định (ý nghĩa): ***Seldom have** I **seen** such a well-organized event.*
- Phủ định (ý nghĩa đã nằm trong Never / Rarely…): ***Never has** the company **missed** a payment.* (không thêm *not*)
- Nghi vấn: đảo ngữ trong câu hỏi là cấu trúc thông thường (*Have you seen…?*); đảo ngữ ở chủ đề này dùng để **nhấn mạnh** trong câu trần thuật.

## Cách dùng

1. Đưa trạng từ / cụm mang **nghĩa phủ định hoặc hạn chế** lên đầu câu để nhấn mạnh, rồi đảo **trợ động từ** lên trước chủ ngữ
   giống câu hỏi (*do / does / did, have / has / had, can, will, should, be*).
   *We have never seen such growth.* → ***Never have we seen** such growth.*
2. Nếu câu gốc không có trợ động từ (hiện tại đơn, quá khứ đơn), mượn **do / does / did** và đưa động từ về nguyên mẫu.
   *He rarely complains.* → ***Rarely does he complain.***
3. **Hardly / Scarcely … when** và **No sooner … than**: vừa mới… thì…; vế đảo ngữ thường ở quá khứ hoàn thành.
4. **Only after / Only when / Not until + mệnh đề**: đảo ngữ ở **mệnh đề thứ hai** (mệnh đề chính), không đảo trong mệnh đề thời gian.
   ***Not until** the contract was signed **did the supplier deliver** the goods.*
5. **So / Such … that** ở đầu câu (mức nâng cao): đảo *be* lên trước chủ ngữ.

## Dấu hiệu nhận biết

- Câu bắt đầu bằng *Never, Rarely, Seldom, Hardly, Scarcely, No sooner, Little, Only…, Not until, Not only, Under no circumstances, On no account*.
- Có cặp *Hardly … when*, *No sooner … than*.
- Câu bắt đầu bằng *So + adj* hoặc *Such + be*, phía sau có *that*.

## Lỗi thường gặp

- ~~Never we have seen~~ → **Never have we** seen.
- ~~Rarely he complains~~ → **Rarely does he complain** (mượn *does*, động từ về nguyên mẫu).
- ~~Rarely does he complains~~ → Rarely does he **complain**.
- ~~No sooner had we arrived when~~ → … **than** …
- ~~Only after did the meeting end, we left.~~ → Only after the meeting ended **did we leave** (đảo ở mệnh đề chính).
- ~~Under no circumstances shouldn't you~~ → Under no circumstances **should** you (không phủ định hai lần).

## Phân biệt với các chủ đề dễ nhầm

- **Đảo ngữ phủ định vs đảo ngữ điều kiện**: *Had I known…, Should you need…, Were I you…* thay cho *if* (chủ đề câu điều kiện hỗn hợp);
  *Never have I known…* là nhấn mạnh phủ định.
- **Not only … but also (liên từ) vs Not only đầu câu (đảo ngữ)**: *She **not only** speaks French **but also** Thai.* (không đảo) /
  ***Not only does** she speak French, but she also speaks Thai.* (đảo).
- **Only + cụm trạng ngữ đầu câu vs only giữa câu**: *We only realized it later.* (không đảo) / ***Only later did we realize** it.* (đảo).
