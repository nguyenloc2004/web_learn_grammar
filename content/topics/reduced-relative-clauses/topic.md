# Rút gọn mệnh đề quan hệ

## Công thức

| Mệnh đề đầy đủ | Rút gọn | Ví dụ |
|---|---|---|
| N + who / which / that + V (chủ động) | N + **V-ing** | *the man **who is sitting** there* → *the man **sitting** there* |
| N + who / which / that + be + V3 (bị động) | N + **V3** | *the files **which were attached*** → *the files **attached*** |
| the first / the last / the only / so sánh nhất + N + who / that + V | N + **to V** (chủ động) / **to be V3** (bị động) | *the first person **to arrive***; *the only candidate **to be invited*** |
| Phân từ đứng trước danh từ | **V-ing** (gây ra / đang diễn ra) / **V3** (bị tác động / đã hoàn tất) | *a **growing** number*, *the **attached** file*, ***detailed** information* |

- Khẳng định: *The documents **attached** to this email are confidential.*
- Phủ định: *Employees **not wishing** to attend should inform HR.*
- Nghi vấn: *Did you read the report **sent** by the auditors?*

## Cách dùng

1. **V-ing** khi danh từ **tự thực hiện** hành động (chủ động), dùng được cả với động từ thường không chia tiếp diễn.
   *Customers **wishing** to cancel their orders should call us.* (= who wish)
2. **V3** khi danh từ **bị tác động** (bị động).
   *All products **made** in this factory are exported.* (= which are made)
3. **to V** sau **the first / the last / the only / the next / so sánh nhất**; bị động là **to be V3**.
   *She was **the first employee to complete** the course.*
4. **Mệnh đề không xác định** cũng rút gọn được, giữ nguyên dấu phẩy.
   *The new policy, **announced** last week, takes effect in May.*
5. **Phân từ làm tính từ**: V-ing mang nghĩa "gây ra" (*an exciting opportunity*), V3 mang nghĩa "bị / cảm thấy" (*interested participants*, *the attached file*).

## Dấu hiệu nhận biết

- Câu đã có động từ chính, chỗ trống đứng **ngay sau danh từ** → cần V-ing / V3 / to V, không thêm động từ chia.
- Sau chỗ trống có **by + người / tổ chức**, hoặc danh từ không thể tự làm hành động → **V3**.
- Sau chỗ trống có **tân ngữ** → thường là **V-ing** (chủ động).
- Có **the first / the last / the only** trước danh từ → **to V**.
- Người cảm thấy → **-ed** (*interested*); sự vật gây cảm xúc → **-ing** (*interesting*).

## Lỗi thường gặp

- ~~All packages sending after 3 p.m.~~ → packages **sent** (gói hàng được gửi).
- ~~the documents attaching to this email~~ → the documents **attached**.
- ~~Participants interesting in the workshop~~ → Participants **interested** in the workshop.
- Giữ lại động từ chia: ~~Employees are wishing to attend must register.~~ → Employees **wishing** to attend …
- ~~the first person receiving the award~~ → the first person **to receive** the award.

## Phân biệt với các chủ đề dễ nhầm

- **Mệnh đề quan hệ vs rút gọn**: *the report **which was submitted** yesterday* → *the report **submitted** yesterday*. Chỉ rút gọn khi bỏ đại từ quan hệ (và *be*) mà nghĩa không đổi.
- **Rút gọn vs câu bị động**: *The report **was submitted** yesterday.* (động từ chính) vs *The report **submitted** yesterday is on your desk.* (bổ nghĩa cho danh từ).
- **Rút gọn mệnh đề quan hệ vs mệnh đề phân từ (participle clauses)**: ở đây phân từ bổ nghĩa cho **danh từ** đứng ngay trước; mệnh đề phân từ thay cho **mệnh đề trạng ngữ** (*Having finished the report, she left.*).
