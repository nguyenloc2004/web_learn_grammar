# Ghi chú riêng: So sánh hơn và so sánh nhất

- **Tiền tố id**: `cs-`
- **Định hướng**: chủ đề hay gặp ở TOEIC Part 5–6 (chọn đúng dạng so sánh, từ nhấn mạnh trước so sánh hơn). Ngữ cảnh ưu tiên:
  công sở, doanh số, báo cáo, nhà cung cấp, sản phẩm, khách hàng, chi nhánh, giao hàng.
- **Phạm vi**: -er/more, -est/most, bất quy tắc (better, worse, further/farther, less, least), the + so sánh nhất + in/of/ever,
  by far, nhấn mạnh so sánh hơn bằng much/far/significantly/considerably/even (không dùng very), one of the + so sánh nhất + N số nhiều,
  the least + adj. So sánh bằng và so sánh kép thuộc chủ đề `comparisons-advanced`.
- **Mức độ**: chỉ sinh `intermediate` và `advanced` (khoảng 60/40). Không sinh `basic`.
- **Dạng câu ưu tiên**: `choose` (giống Part 5) chiếm khoảng 60%, phần còn lại là `fix-error`, `fill-form`, `rewrite`.
- **Lỗi người Việt hay gặp**: more cheaper / most biggest; very better; badder; one of the best employee (quên số nhiều);
  quên the trước so sánh nhất; dùng tính từ thay trạng từ trong so sánh (works more efficient).
- **Tránh**: "the cheaper / the cheapest of the two" (người bản ngữ chấp nhận cả hai), farther/further cho khoảng cách (đều đúng),
  "than any employee" (lỗi logic nhưng phổ biến trong văn nói).
- Tag `toeic-part5` hoặc `toeic-part6` để biết câu mô phỏng phần nào của đề thi.
