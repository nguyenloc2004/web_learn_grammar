# So sánh bằng và so sánh kép (as…as, the more…the more)

## Công thức

| Cấu trúc | Công thức | Ví dụ |
|---|---|---|
| So sánh bằng | **as** + adj / adv (nguyên mẫu) + **as** | *as fast as*, *as carefully as* |
| So sánh không bằng | **not as / not so** + adj / adv + **as** | *not as expensive as* |
| Giống nhau | **the same** + (N) + **as** | *the same price as* |
| Gấp nhiều lần | **twice / three times / half** + as + adj / adv / much / many + as | *twice as large as*, *three times as much as* |
| So sánh kép | **The** + so sánh hơn + S + V, **the** + so sánh hơn + S + V | *The sooner we start, the earlier we finish.* |
| Càng ngày càng | so sánh hơn **and** so sánh hơn / **more and more** + adj dài | *higher and higher*, *more and more popular* |
| Tương tự / khác | **similar to**, **different from** | *similar to ours* |

- Khẳng định: *The new branch is **as busy as** the head office.*
- Phủ định: *This year's budget is **not as large as** last year's.*
- Nghi vấn: *Is the new laptop **as light as** the old one?*

## Cách dùng

1. **as … as**: hai đối tượng ngang nhau. Giữa hai chữ *as* là tính từ / trạng từ ở **dạng nguyên mẫu**.
   *Our prices are **as competitive as** theirs.*
2. **as … as possible**: … nhất có thể. *Please reply **as soon as possible**.*
3. **not as / not so … as**: kém hơn. *The second quarter was **not as profitable as** the first.*
4. **the same + N + as**: giống nhau về một mặt nào đó. *She has **the same job title as** her manager.*
5. **Bội số + as … as**: *The new warehouse is **twice as large as** the old one.* Với danh từ / số lượng: *three times **as much** money / **as many** staff **as***.
6. **The + so sánh hơn …, the + so sánh hơn …**: càng … càng. Tính từ / trạng từ đứng **ngay sau the**.
   *The **more carefully** you check the data, **the fewer** errors you will make.*
7. **So sánh hơn and so sánh hơn**: càng ngày càng. *Costs are getting **higher and higher**.* / *Online shopping is becoming **more and more popular**.*
8. **similar to / different from**: *Our plan is **similar to** yours.* / *The final version is **different from** the draft.*

## Dấu hiệu nhận biết

- Có **as** ở phía sau chỗ trống, hoặc **as … as possible** → so sánh bằng, dùng dạng nguyên mẫu.
- Có **the same** → đi với **as**, không dùng *like / than*.
- Có **twice / three times / half** → bội số + as … as.
- Câu bắt đầu bằng **The + so sánh hơn**, có dấu phẩy và vế sau cũng bắt đầu bằng **the** → so sánh kép.
- Có **becoming / getting / growing** + so sánh hơn lặp lại → càng ngày càng.

## Lỗi thường gặp

- ~~as larger as~~, ~~as large than~~ → **as large as**.
- ~~the same software like / than~~ → the same software **as**.
- ~~similar with~~ → **similar to**.
- ~~The more the proposal is detailed, …~~ → **The more detailed** the proposal is, …
- Quên **the** ở vế sau: ~~The sooner we start, we finish earlier.~~ → …, **the earlier** we finish.
- ~~high and high~~, ~~more and more high~~ → **higher and higher**.
- ~~twice larger as~~ → **twice as large as**.

## Phân biệt với các chủ đề dễ nhầm

- **as … as (bằng) vs so sánh hơn (than)**: *as fast as* vs *faster than*; không trộn *as … than*.
- **as + adj + as vs as + adv + as**: phụ thuộc vào từ đứng trước: *is as **quick** as* (sau *to be*) vs *works as **quickly** as* (bổ nghĩa cho động từ).
- **as much as vs as many as**: *much* cho danh từ không đếm được / số tiền, *many* cho danh từ đếm được số nhiều.
- **different from**: là cách dùng chuẩn trong văn viết trang trọng; trong bài thi nên dùng *from*.
