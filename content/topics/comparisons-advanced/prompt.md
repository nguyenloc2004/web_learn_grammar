# Ghi chú riêng: So sánh bằng và so sánh kép

- **Tiền tố id**: `ca-`
- **Định hướng**: TOEIC Part 5–6. Ngữ cảnh ưu tiên: công sở, giá cả, chi phí, nhà kho, nhà cung cấp, chi nhánh, khách hàng, đặt chỗ.
- **Phạm vi**: as + adj/adv + as, as … as possible, not as/so … as, the same + N + as, twice/three times/half as … as (as much / as many),
  the + so sánh hơn …, the + so sánh hơn …, so sánh hơn and so sánh hơn (more and more), similar to, different from.
  So sánh hơn / nhất đơn thuần thuộc chủ đề `comparatives-superlatives`.
- **Mức độ**: chỉ sinh `intermediate` và `advanced` (khoảng 60/40). Không sinh `basic`.
- **Dạng câu ưu tiên**: `choose` (giống Part 5) chiếm khoảng 60%, phần còn lại là `fix-error`, `fill-form`, `rewrite`.
- **Lỗi người Việt hay gặp**: as larger as / as large than; the same … like; similar with; quên the ở vế sau của so sánh kép;
  "The more the proposal is detailed"; high and high.
- **Tránh**: câu chỉ phân biệt "not as" và "not so" (cả hai đúng), "different to / different than" (biến thể Anh–Mỹ),
  "three times more than" (người bản ngữ chấp nhận), "as early as possible" khi đáp án là "as soon as possible".
- Tag `toeic-part5` hoặc `toeic-part6` để biết câu mô phỏng phần nào của đề thi.
